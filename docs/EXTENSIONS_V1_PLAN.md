# 补充实验 v1：固定范围与执行顺序

依据用户提供的最新论文、补充实验执行清单、任务书与定稿说明执行。材料是本次研究方案的依据；投稿、作者声明等工作不在本次实验与 GitHub 同步范围内。附件及其元数据清单保留在本地；公开仓库提供实验协议、代码和实验结果。

基准是 `cea4f4fa830fa3ee87a2af0041711951b5388be4`。更名后的仓库 `qoxgain/long_tail_items_recommendation` 在起始提交 `832730b6eba97c91a795978a6366ca2ffe973026` 只修改了 README 项目名称。旧数据、模型、预测和报告仍在本地，优先核验复用；不重新解释旧结果为独立确认。

不可变的全局方案在 [extensions_v1.json](../configs/extensions_v1.json)，SHA256 单独保存。原始核心模块保持不变，新训练和统计放在扩展模块。每阶段另外冻结最终代码、配置、输入和依赖哈希。方案变更须使用新版本，不因已看到最终结果而修改模型、时间或终点。

## 本轮执行矩阵

| 阶段 | 内容 | 规定数量和证据身份 |
|---|---|---|
| A | 旧材料复核、三项新增目标配对、两项既有配对、商品簇区间、选择曲线、全部指标与机制 | 旧开发结果的新增分析，不训练 |
| B1/B2 | MF-BPR、原生和用户检索 LightGCN、SimpleX、平均和组合历史 | 216 条历史选择轨迹，90 条最终轨迹；原 2015–2017 年开发分析 |
| C1/C2 | 平均和组合底座，零/均匀/语义/完整效用，新音乐时间段 | 24 个历史效用目标、每底座 37 个部署选择配置、120 个最终策略评价及 3 个活动基线 |
| C3 | Movies and TV → Books | 资源条件满足后另行开展；不计入本轮规定完成矩阵，也不宣称已经验证 |

B 的三个历史种子为 101/202/303，最终仍为 11/22/33/44/55。只在第 6、20、50 轮检查点上选配置及预算；每轮历史指标保留用于收敛曲线。若某族第 50 轮最优，且同配置相对第 20 轮提高至少 1%，该族全部候选延长至 100 轮。分母绝对值小于 `1e-8` 时使用绝对提升 `1e-4`。平局优先较少轮次，再按原网格顺序。不使用最终查询决定是否延长。

C 固定 2018、2019、2020 年 1 月 1 日 UTC。底座采用旧 2015 年已冻结的平均/组合历史配置、六轮训练；历史效用模型与其部署底座配置一致。各底座的源强度仅在 2018 d30 选择一次，此后冻结。该选择与 B 的预算扩展独立，不根据 B 或 C 的最终结果重新选 C 的目标底座。全局协议冻结前，没有在可用工作区或聊天中发现这些新时间查询的评价记录；无法核实工作区之外是否有人查看过，故称本流程的新时间验证，不称独立领域验证。

## 存储、资源与状态

新产物放入 `data_extensions/v1/`、`results_extensions/v1/`、`reports/extensions_v1/`。旧 `results/` 和根目录 `reports/` 保持可核对。最终严格汇总分别列出已运行、校验复用、失败、缺失和资源未排程项目；监测用途的部分结果不得称全部完成。

第二领域的官方 HEAD 响应给出约 13.8 GB 压缩输入：Books 评分 6,216,820,644 字节、元数据 4,942,125,770 字节；Movies and TV 评分 2,396,672,075 字节、元数据 271,381,871 字节。当前文件系统总量 32 GB，尚需保留原工件及 B 的模型和优化器检查点。先实测本轮训练预算，再评估新领域所需投影、缓存和训练空间；不截取下载流冒充完整数据。

每个进程固定一个数值线程，训练并行进程最多三个。运行时间采用历史试点实测估算，峰值内存与实际配对/更新次数随轨迹保存。不能用相同 epoch 声称不同训练目标计算量相同。
