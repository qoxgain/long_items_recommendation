# 重建范围与证据边界

本工程是在原实验代码与检查点无法恢复后，根据用户重新提供的三份 DOCX 以及聊天中的协议记录独立重建。它不是原代码包的镜像；旧报告中的数值和“106 项测试通过”不是本工程的运行证明。

重建主线为第三轮的紧接拟合截止后 30 天商品检索用户任务：五个目标模型、MF-BPR / LightGCN / SimpleX、历史源收益回归、冻结目标底座的受限修正和精确零迁移。所有前缀独立选择用户、目录、词表、SVD 和活动标准化。完整候选评价，固定训练轮数，历史块选参。

原始第二轮模型、选中检查点和逐商品预测已丢失，无法重新进行原报告 A 阶段的检查点重放，也不能把新实现的不同训练过程冒充原 B 阶段的覆盖审计。这些内容仅作为历史依据引用。联合词表、现代冻结编码器、混合负采样、完整候选 softmax、新类别确认仍属于独立扩展轴，完成与否以本工程运行清单为准。

原报告未保留完整的特征映射和全部优化细节。本次明确采用 `unit(concat(h, x*h, abs(x-h)))` 作为 192 维偏好特征；每个模块记录其他重建选择。实验前固定这些选择，不根据与历史数值的接近程度调整它们。数据来源版本、依赖版本、采样轨迹和这些实现选择均可能导致数值变化。

`reports/historical_reference.csv` 仅转录用户提供的报告。新运行记录写入 `results/`，汇总表和报告由代码读取这些记录生成；二者不得混合。少量优化种子与三个音乐时间起点仍属于开发实验，不能表述为新类别独立验证。

公开 GitHub 仓库保存代码、协议、测试、公开数据下载方法及聚合结果。原始评分、大型检查点、特征缓存和用户提供的完整论文附件不随常规 Git 提交；代码可从公开数据重建本地工件。
